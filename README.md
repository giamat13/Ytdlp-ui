# yt-dlp UI

ממשק דפדפן מקומי ופשוט ל-[yt-dlp](https://github.com/yt-dlp/yt-dlp): מדביקים קישור, בודקים, ומורידים. השרת רץ רק על המחשב שלך (`127.0.0.1`) ולא נגיש מהרשת.

## דרישות

- Python 3.10 ומעלה
- [ffmpeg](https://ffmpeg.org/) — נדרש למיזוג וידאו+שמע ולהמרת אודיו. בלעדיו הורדת וידאו עובדת בקובץ אחד (לפי הפורמט הזמין), אבל מיזוג והמרה לא.

התקנת ffmpeg ב-Windows:

```powershell
winget install Gyan.FFmpeg
```

## התקנה והרצה

```bash
pip install -r requirements.txt
python main.py
```

ואז פתחו בדפדפן: http://127.0.0.1:8765

אפשרויות שורת פקודה:

```bash
python main.py --out D:/Videos   # תיקיית הורדה אחרת (ברירת מחדל: ~/Downloads/yt-dlp)
python main.py --open            # פתיחת הדפדפן אוטומטית
python main.py --port 9000       # פורט אחר
```

## שימוש

1. הדביקו קישור לסרטון, לפלייליסט או לאתר נתמך.
2. לחצו **בדוק** כדי לראות כותרת, תמונה ואיכויות זמינות.
3. בחרו וידאו או אודיו, איכות, ואם צריך כתוביות.
4. לחצו **הורד**. ההורדות רצות ברקע, ואפשר לעקוב אחריהן ברשימה.

## פרטיות ואבטחה

- השרת מאזין רק ל-`127.0.0.1` כברירת מחדל.
- הבקשות מהדפדפן נדרשות להיות JSON, כך שאתר זר לא יכול להפעיל הורדות בלי אישור preflight.
